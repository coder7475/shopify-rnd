## ✅ New Creator Platform Checklist (Week 1)

Complete before you start posting:

- [ ] Profile photo: Clear, high-quality, brand-consistent across all platforms
- [ ] Bio: States who you are, who you serve, and what you offer (include a niche keyword)
- [ ] Bio link: Linktree or similar — affiliate links organized by category (bags, accessories, etc.)
- [ ] First 3 posts: Published before you start actively promoting your account
- [ ] Posting schedule: Defined and realistic for your weekly capacity
- [ ] Analytics: Enabled and verified on all platforms
- [ ] UTM tracking: Set up on all affiliate and external links (`?utm_source=tiktok&utm_medium=bio`)
- [ ] Disclosure template: Saved and ready (`#affiliate` / `#ad` copy to paste)

## ✅ Pre-Publish: Video Checklist (TikTok / Instagram Reels / YouTube)

Run through before every video publish:

**Hook & Structure**
- [ ] Hook lands in first 1–2 seconds (curiosity, controversy, or direct value)
- [ ] Content delivers on the hook's promise
- [ ] Call to action stated clearly before the last 5 seconds ("link in bio", "tap the bag icon")

**Optimization**
- [ ] Primary keyword in title/caption (first 60 characters for YouTube titles)
- [ ] Description written: 200+ words (YouTube) or keyword-rich caption (TikTok/IG)
- [ ] Affiliate product tagged in-video OR affiliate link in description with UTM tracking
- [ ] Closed captions added (required for accessibility + platform SEO indexing)
- [ ] Thumbnail set: high-contrast, readable text, emotional hook (YouTube)

**Compliance & Quality**
- [ ] No competitor platform watermarks (no TikTok logo on Instagram Reels)
- [ ] Disclosure added if affiliate or paid: `#affiliate` / `#ad` / `#sponsored`
- [ ] Audio levels checked: clear speech, no background clipping
- [ ] Video resolution: minimum 1080p (9:16 vertical for TikTok/Reels; 16:9 for YouTube)

## ✅ Pre-Publish: Blog Post Checklist

Run through before every blog post publish:

**SEO Fundamentals**
- [ ] Title tag: < 60 characters, primary keyword first
  *Example:* `Best Waxed Canvas Bags 2026: Tested & Ranked | [Brand]`
- [ ] Meta description: < 155 characters, benefit + call to action
- [ ] URL slug: clean, keyword-based, no dates (e.g., `/best-waxed-canvas-bags`)
- [ ] H1: Matches search intent, one per page only
- [ ] H2/H3: Used to break up sections with secondary keywords

**Content Quality**
- [ ] 800+ words of original, useful content
- [ ] Opening paragraph directly answers the main question (important for AI snippets)
- [ ] Comparison table included if applicable (tables rank well and AI pulls them)
- [ ] FAQ section: 3–5 direct Q&A pairs at the bottom of the post
- [ ] Product spotlight with affiliate link: integrated naturally into the content

**Technical**
- [ ] All images have descriptive alt text (`"olive green canvas tote bag front view"`)
- [ ] 2–3 internal links to related posts/pages
- [ ] All affiliate links include UTM tracking and `rel="nofollow sponsored"` attribute
- [ ] Disclosure statement at the top: *"This post contains affiliate links. I may earn a commission at no extra cost to you."*

## ✅ Pre-Publish: Pinterest Pin Checklist

Run through before every pin publish:

**Visual**
- [ ] Format: 2:3 vertical (1000 × 1500 px) — strictly required
- [ ] Product shown in aspirational lifestyle context (not plain white background)
- [ ] Text overlay: clear, readable, hooks curiosity or promises a benefit
- [ ] Brand logo or watermark added (subtle, corner placement)

**Copy**
- [ ] Title: Primary keyword first, followed by product benefit
  *Example:* `Minimalist Travel Bag — Carry-On Approved, Fits 16" Laptop`
- [ ] Description: 150–300 words with natural keyword phrases woven in (not stuffed)
- [ ] Description ends with a soft CTA: "Click to shop" or "See full review"

**Destination**
- [ ] Link: Direct affiliate/product URL (not homepage)
- [ ] UTM tracking added: `?utm_source=pinterest&utm_medium=pin`
- [ ] Board: Added to a specific niche board (e.g., "Minimalist Travel Bags") — not a broad board

## ✅ Monthly Creator Review Checklist

Run on the last day of each month:

**Content Performance**
- [ ] Identify top 5 posts by saves (quality indicator)
- [ ] Identify top 5 posts by affiliate link clicks (revenue indicator)
- [ ] Note which content format dominated both lists — plan more of it
- [ ] Repurpose the #1 performing post to 2 other platforms this week

**Revenue Audit**
- [ ] Total affiliate earnings by platform (TikTok / Instagram / YouTube / Pinterest)
- [ ] Which specific products converted? Which had clicks but no conversions?
- [ ] Remove underperforming products from bio link; promote top converters
- [ ] Review brand deal pipeline: any open proposals or follow-ups needed?

**SEO & Evergreen**
- [ ] Open Google Search Console: any new keywords gaining impressions?
- [ ] Any pages ranking positions 5–20? (Easy to push into top 3 with a few tweaks)
- [ ] Update 1 evergreen post: refresh affiliate links, update pricing, add new FAQ
- [ ] Review bio link page: are all affiliate links active and correctly tracked?

**Planning**
- [ ] Plan next month's content calendar based on this month's top performers
- [ ] Identify 1 new long-tail keyword to target for SEO content
- [ ] Set a specific revenue goal for next month with a plan to hit it

## ✅ Shopify Store Launch Checklist (If Selling Own Products)

Before going live:

**Products**
- [ ] All products have specific, descriptive titles (include material, dimensions, use-case)
- [ ] All products have 150+ word original descriptions explaining the problem they solve
- [ ] All product images have descriptive alt text
- [ ] Valid GTIN/barcode added (or flagged as custom product)
- [ ] All variants (size, color, etc.) fully configured with correct pricing

**Store Infrastructure**
- [ ] Shop Pay enabled (`Settings > Payments`)
- [ ] Facebook & Instagram app installed with Maximum Data Sharing
- [ ] TikTok app installed and linked to Seller Center
- [ ] Pinterest app installed with Hosted Checkout enabled
- [ ] Google & YouTube app installed with GA4 linked
- [ ] All tracking via Web Pixels (NOT Additional Scripts — deprecated Aug 26, 2026)
- [ ] Agentic Storefronts enabled (`Settings > Sales Channels > Agentic Storefronts`)

**Policies**
- [ ] Return policy: plain HTML, direct language, no PDF links
- [ ] Shipping policy: accurate rates matching checkout
- [ ] Privacy policy: up to date
- [ ] All policy pages linked in footer
