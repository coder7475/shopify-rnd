## 7.1 What to Track and Why

Most creators track vanity metrics (followers, likes) and ignore the numbers that actually drive revenue. This guide focuses on **actionable metrics** — ones that tell you exactly what to do next.

```
METRICS HIERARCHY

Tier 1 — Revenue (ultimate goal)
  Affiliate earnings | Brand deal income | Store revenue | RPM

Tier 2 — Conversion (bridge from content to revenue)
  Link CTR | Affiliate conversion rate | Store conversion rate

Tier 3 — Engagement (quality signal)
  Saves | Shares | Comments | Watch completion rate

Tier 4 — Reach (vanity, but necessary foundation)
  Views | Impressions | Follower count
```

## 7.2 Audience Growth Metrics (Platform Health)

| Metric | Target | What It Tells You | Where to Find It |
| :--- | :--- | :--- | :--- |
| **Follower Growth Rate** | > 3–5% / month | Is your content attracting new people? | Native platform analytics |
| **Engagement Rate** | > 3–5% on IG, > 5–8% on TikTok | Are your followers actually engaged? | `(likes + comments + saves) / reach × 100` |
| **Watch Completion Rate** | > 50% | Is your content worth watching to the end? | TikTok Analytics / YouTube Studio |
| **Saves Rate** | > 2–3% of views | Is your content valuable enough to save? | Instagram Insights / TikTok Analytics |
| **DM Shares per Reel** | Rising trend | Is content shareable (Instagram's top signal)? | Instagram Insights → Sends |

## 7.3 Revenue Metrics (Monetization Health)

| Metric | Formula | Target | Why It Matters |
| :--- | :--- | :--- | :--- |
| **Affiliate Earnings per Video** | Total affiliate $ ÷ # of videos | Track trend month-over-month | Which content type earns most? |
| **Link Click-Through Rate (CTR)** | Link clicks ÷ views × 100 | > 1–3% | Are viewers taking action? |
| **Affiliate Conversion Rate** | Purchases ÷ link clicks × 100 | > 2–5% | Does your audience buy what you recommend? |
| **Revenue Per 1,000 Views (RPM)** | Total revenue ÷ (views ÷ 1,000) | Benchmark vs. your niche average | True monetization efficiency |

**RPM Benchmarks by Niche (2026 estimates):**
| Niche | Typical RPM Range |
| :--- | :--- |
| Finance / Business | $15–$50 |
| Tech / Software | $10–$35 |
| Travel | $5–$20 |
| Fashion / Lifestyle | $3–$12 |
| Entertainment | $1–$5 |

## 7.4 Store Metrics (If Selling Own Products)

| Metric | Target | Interpretation | Action if Below Target |
| :--- | :--- | :--- | :--- |
| **Store Conversion Rate** | > 2.0–3.5% | Is your landing page converting traffic? | Improve PDP copy, add FAQs, speed up page |
| **ROAS (Return on Ad Spend)** | > 2.5x break-even | Is paid amplification profitable? | Pause underperforming creatives; test new hooks |
| **Thumbstop Rate** | > 25–35% | Hook strength (first 3 seconds) | Rewrite opening hook; test controversy/curiosity |
| **Hold Rate** | > 20–30% | Story quality (% watching to 50%) | Tighten editing; front-load value |
| **Outbound CTR** | > 1.2–2.0% | Are viewers clicking through? | Below 1% = fatigued creative; refresh |
| **Cart Abandonment Rate** | < 70% | Checkout friction? | Add trust signals; simplify checkout; enable Shop Pay |

## 7.5 Free Analytics Tools Setup

| Tool | What to Track | How to Set Up |
| :--- | :--- | :--- |
| **Google Analytics 4 (GA4)** | Blog traffic, affiliate link clicks, store conversions, audience source | Connect via Google & YouTube Shopify app; verify with realtime report |
| **Google Search Console (GSC)** | Which Google keywords drive traffic; indexing errors; page impressions | Verify via HTML tag in `theme.liquid`; submit `sitemap.xml` |
| **TikTok Creator Center** | Video performance, follower demographics, affiliate dashboard | Built into TikTok app under Creator Tools |
| **Instagram Insights** | Reach, saves, shares, profile visits, audience demographics | Built into Professional Account (tap bar chart icon) |
| **Pinterest Analytics** | Pin impressions, outbound clicks, top boards, audience demographics | Built into Pinterest Business Hub |
| **YouTube Studio** | Watch time, CTR, revenue, top content, audience retention graph | studio.youtube.com |

## 7.6 Monthly Performance Review Ritual

Run this review on the last day of each month (takes ~1 hour):

```
MONTHLY CREATOR REVIEW AGENDA

1. Top Content (15 min)
   → Which 5 posts got the most saves?
   → Which 5 posts drove the most affiliate clicks?
   → Do these match? If not, why?

2. Revenue Audit (15 min)
   → Total affiliate earnings by platform
   → Which products converted? Which didn't?
   → Brand deal pipeline: any open proposals?

3. SEO Check (15 min)
   → Google Search Console: new keywords gaining impressions?
   → Any blog posts ranking in positions 5–20? (Easy wins to optimize)
   → YouTube: which videos are getting suggested traffic?

4. Action Items (15 min)
   → Repurpose top performer to 2 other platforms
   → Update 1 evergreen post with fresher data / product links
   → Plan next month's content around top-performing topics
```
