## 🏛️ Archive Policy & Conventions

To maintain a clean documentation repository without losing valuable decision records or context:
1. **Never Silently Delete**: Technical documents containing architecture rationales, test notes, or initial evaluations are moved here rather than permanently deleted.
2. **Canonical Links**: Every archived document listed below points directly to its active, canonical successor.
3. **Immutable History**: Archived documents remain unmodified once deposited; all new updates must occur in the canonical document.
